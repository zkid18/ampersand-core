This page sets up the server that stores your vault and exposes the HTTP API. Once it's running, install [the CLI](/cli-install) on your laptop to talk to it.

## What you need

- An Ubuntu 22.04+ box you can SSH into as root. A 1 GB DigitalOcean droplet ($4/mo) is the reference target.
- A domain name (optional today, recommended before this server goes public).
- An OpenAI API key (optional — required for semantic search, hybrid rerank, YouTube audio fallback).

## One-command bootstrap

SSH in as root, then:

```bash
git clone https://github.com/zkid18/ampersand-core /opt/amperstand/amperstand-core
cd /opt/amperstand/amperstand-core
sudo bash deploy/bootstrap.sh
```

`deploy/bootstrap.sh` is the production install. Re-running it is safe — every step checks before doing.

### What bootstrap does

1. Installs apt packages: Python 3, Caddy, ufw, git, curl
2. Creates a dedicated `amperstand` system user
3. Generates `AMPERSTAND_API_KEY` (a 64-char hex token) and writes it to `/etc/amperstand/env` mode 0640
4. Builds a Python venv at `/opt/amperstand/venv`, installs the server editable from this clone
5. Installs systemd units: `amperstand-server.service`, `amperstand-vault-watcher.service`, `amperstand-feed-sync.timer`. The email-watch unit is installed but stays disabled until you configure IMAP.
6. Configures Caddy (HTTP only by default; bundled `Caddyfile.tls` for later)
7. Opens ports 22/80/443 in UFW
8. Starts `amperstand-server`, waits for `/health`, prints the API key once

When it finishes, **copy the printed API key** — you'll paste it as `AMPERSTAND_API_KEY` on every client.

## Add an OpenAI key (recommended)

Embeddings, hybrid-search rerank, and YouTube audio-fallback all use the OpenAI API. To enable them:

```bash
sudo nano /etc/amperstand/env
# add the line:
# OPENAI_API_KEY=sk-...

sudo systemctl restart amperstand-server
```

Without it:

| Feature | State |
| --- | --- |
| Capture (articles, transcripts, RSS, email) | Works |
| Keyword search (`/v1/docs/search`) | Works |
| Semantic search (`/v1/docs/search/semantic`) | Returns `503` |
| Hybrid search (`/v1/docs/search/hybrid`) | Degrades to FTS5-only |
| YouTube audio-fallback transcripts | Disabled |

Model: `text-embedding-3-small`, ~$0.02 per 1,000 docs.

See [Configuration](/configuration) for every server env var.

## Verify it's running

```bash
curl http://<your-server-ip>/health
# {"status":"ok"}
```

Or, once you've installed the CLI on your laptop:

```bash
amperstand vault status
# Server: ok
# Docs: 0
```

## Manual install (if you don't want bootstrap)

If you'd rather do it by hand:

```bash
# 1. Clone the server
git clone https://github.com/zkid18/ampersand-core /opt/amperstand/amperstand-core
cd /opt/amperstand/amperstand-core

# 2. Make a venv and install
python3 -m venv /opt/amperstand/venv
/opt/amperstand/venv/bin/pip install -e .

# 3. Set env vars
sudo mkdir -p /etc/amperstand
sudo tee /etc/amperstand/env <<EOF
AMPERSTAND_API_KEY=$(openssl rand -hex 32)
AMPERSTAND_DATA_DIR=/var/lib/amperstand/vault
EOF
sudo chmod 0640 /etc/amperstand/env

# 4. Run the server
source /etc/amperstand/env
export AMPERSTAND_API_KEY AMPERSTAND_DATA_DIR
/opt/amperstand/venv/bin/amperstand-server --host 0.0.0.0 --port 8765
```

You'll then need to set up systemd + Caddy yourself — see [Deployment](/deployment) for the production layout.
